## Qué incluye este repo

- `notebooks`: Carpeta de todas las pruebas de los codigos demostrando que si funcionan y cumplen con los requisitos.
- `src`: Carpeta que contiene el codigo detras de cada calculo, función, escenario, simulación usado durante el proyecto.
